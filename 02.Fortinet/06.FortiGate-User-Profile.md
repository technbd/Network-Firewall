## Admin User and Admin Profile:



_Example of Admin Profile:_
```
Admin Profile
     │
     ├── System
     │   ├── Read
     │   └── Read/Write
     │
     ├── Network
     │   ├── Read
     │   └── Read/Write
     │
     ├── Firewall
     │   ├── Read
     │   └── Read/Write
     │
     └── VPN
         ├── Read
         └── Read/Write
```


_Typical access levels are:_

| Permission     | Meaning                                            |
| -------------- | -------------------------------------------------- |
| **None**       | No access                                          |
| **Read**       | Can view configuration                             |
| **Read/Write** | Can view and modify                                |
| **Custom**     | Granular permissions, depending on FortiOS version |

## Configure Admin Profile and User on Firewall:

### Create Admin Profile: 

An **Admin Profile** defines what an administrator is allowed to do.

1. Navigate to: `System` - `Admin Profiles` - Click `+ Create New`:
    - Name: `profile-read-only`
    - Comments:
    - Access Permissions:
        - Security Fabric:
        - FortiView:	
        - User & Device:	
        - Firewall:	`Read`
        - Log & Report:	`Read`
        - Network: `Read`	
        - System: `Read`
        - Security Profile:	
        - VPN:	
        - WAN Opt & Cache:	
        - WiFi & Switch:
    - Click `OK`


### Create User: 

An `Admin` User is the account used to log in to FortiGate.


1. Navigate to: `System` - `Administrators` - Click `+ Create New` - select `Administrator`:
    - Username: `demo`
    - Type: `Local User`
    - Password: 
    - Confirm Password: 
    - Comments: 
    - Administrator Profile: `profile-read-only`
    - ❌ Two-factor Authentication
    - ❌ Restrict login to trusted hosts
    - ❌ Restrict admin to guest account provisioning only
    - Click `OK`

## Create Firewall Policy:


### Allow to Internet: 

This is the firewall policy that allows network `192.168.13.0/24` to reach `8.8.8.8`


1. Navigate to: `Policy & Objects` - `IPv4 Policy/Firewall Policy` - click `+ Create New`:
    - Name: `host-group-Lan-13-allow-to-WAN`
    - Incoming Interface: `LAN (port5)`
    - Outgoing Interface: `WAN (port4)`
    - Source: `host-group-Lan-13` 
    - Destination: `all` 
    - Schedule: `always`
    - Service: `ALL` 
    - Action: `ACCEPT`
    - Inspection Mode: `Flow-based` 
    - Firewall / Network Options: 
        - NAT: ❌ 
        - Protocol Options: `default`
    - Security Profiles:
        - AntiVirus: ❌
        - Web Filter: ❌
        - DNS Filter: ❌
        - Application Control: ❌
        - IPS: ✅ `default`
        - SSL Inspection: `certificate-inspection`
    - Logging Options:
        - Log Allowed Traffic: ✅ `Security Events` 
        - Generate Logs when Session Starts: ❌
        - Capture Packets: ❌
    - Comments: 
    - Enable this policy: ✅ 
    - Click `OK`

## Configure Service and Service Group on Firewall: 
 


### Create Service: 


1. Navigate to: `Policy & Objects` - `Services` - click `+ Create New` - click `Service` :
    - Name: `custom-http-service`
    - Comments: `allow-http-port-80`
    - Color: 
    - Show in Service List: ✅
    - Category: `Uncategorized`
    - Protocol Options: 
        - Protocol Type: `TCP/UDP/SCTP`
        - Address: `IP Range` | `FQDN` : [`0.0.0.0`]
        - Destination Port: `TCP`: 
            - Low: `80`
            - High: `80`
        - Specify Source Ports: ❌
    - Click `OK`



1. Navigate to: `Policy & Objects` - `Services` - click `+ Create New` - click `Service` :
    - Name: `custom-http-app-service`
    - Comments: `allow-http-port-8080`
    - Color: 
    - Show in Service List: ✅
    - Category: `Uncategorized`
    - Protocol Options: 
        - Protocol Type: `TCP/UDP/SCTP`
        - Address: `IP Range` | `FQDN` : [`0.0.0.0`]
        - Destination Port: `TCP`: 
            - Low: `8080`
            - High: `8080`
        - Specify Source Ports: ❌
    - Click `OK`





### Create Service Group: 

1. Navigate to: `Policy & Objects` - `Services` - click `+ Create New` - click `Service Group` :
    - Group name: `custom-http-service-group`
    - Comments:
    - Color: 
    - Members: `custom-http-service` and `custom-http-app-service` (<-- also add: `ALL_ICMP`, `HTTP`, `HTTPS`)
    - Click `OK`

## Create Firewall Policy:


### Allow to Internet: 

This is the firewall policy that allows network `192.168.13.0/24` to reach `8.8.8.8`


1. Navigate to: `Policy & Objects` - `IPv4 Policy/Firewall Policy` - click `+ Create New`:
    - Name: `allow-Lan-13-to-WAN`
    - Incoming Interface: `LAN (port5)`
    - Outgoing Interface: `WAN (port4)`
    - Source: `host-group-Lan-13` 
    - Destination: `all` 
    - Schedule: `always`
    - Service: `custom-http-service-group`  (<-- Custom Service)
    - Action: `ACCEPT`
    - Inspection Mode: `Flow-based` 
    - Firewall / Network Options: 
        - NAT: ❌ 
        - Protocol Options: `default`
    - Security Profiles:
        - AntiVirus: ❌
        - Web Filter: ❌
        - DNS Filter: ❌
        - Application Control: ❌
        - IPS: ✅ `default`
        - SSL Inspection: `certificate-inspection`
    - Logging Options:
        - Log Allowed Traffic: ✅ `Security Events` 
        - Generate Logs when Session Starts: ❌
        - Capture Packets: ❌
    - Comments: 
    - Enable this policy: ✅ 
    - Click `OK`

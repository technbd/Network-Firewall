## QEMU Setup:

QEMU on EVE-NG allows you to emulate a wide variety of **devices**, **including servers**, **routers**, and **switches**. Here’s a step-by-step guide to get QEMU running on EVE-NG:



### Upload QEMU Images to EVE-NG:

Navigate to `/opt/unetlab/addons/qemu/` and **create a directory for your device** (like: `fortinet-v6.2.3`) and upload the QEMU image (e.g., `virtioa.qcow2`) to this directory.


```bash
cd /opt/unetlab/addons/qemu/
```


```bash
mkdir fortinet-v6.2.3
```



```bash
ll /opt/unetlab/addons/qemu/

drwxr-xr-x 2 root root 4096 Jul  9 17:23 fortinet-v6.2.3
```



```bash
ll /opt/unetlab/addons/qemu/fortinet-v6.2.3


-rw-r--r-- 1 root root 61865984 Sep 15 10:02 virtioa.qcow2
```



### Fix Permissions:

After uploading the QEMU images, you need to set the correct permissions.

```
/opt/unetlab/wrappers/unl_wrapper -a fixpermissions
```

## Install `ishare2` cli: 



_One-line installation:_
```bash
wget -O /usr/sbin/ishare2 https://raw.githubusercontent.com/pnetlabrepo/ishare2/main/ishare2 > /dev/null 2>&1 && chmod +x /usr/sbin/ishare2 && ishare2

Or,
wget -qO- https://ishare2.sh/install | sh

Or,
curl https://ishare2.sh/install | sh
```



```bash 
which ishare2
```




_If you prefer manual installation:_
```bash
git clone https://github.com/ishare2-org/ishare2-cli.git

cp ishare2-cli/ishare2 /usr/sbin/ishare2
chmod +x /usr/sbin/ishare2

mkdir -p /opt/ishare2/cli/lib
cp ishare2-cli/lib/*.sh /opt/ishare2/cli/lib/
```



```
ishare2


Syntax
ishare2 [action] [param1] [param2] [--overwrite]

action:
    search      : Search for images available on LabHub mirrors.
    pull        : Download an image by specifying the type and id.
    installed   : Shows images installed on the server.
    labs        : Shows available labs and downloads the images for the selected lab.
    mylabs      : Same as labs command but you can use a customized path.
    relicense   : Generates an iourc license for iol images.
    upgrade     : Shows a menu to upgrade ishare2 or ishare2 GUI.
    test        : Test internet connectivity to required sites.
    help        : Shows full help information.

param1:
    type = all, iol, qemu, dynamips, docker or name.

param2:
    id = This can be obtained using ishare2 search <type>

--overwrite:
    Used to overwrite an existing image if it already exists on your system.
```

### Search for images: 

_Search by name:_
```bash
ishare2 search all        # This command will show all available images of all types

ishare2 search winserver  # Will show all Windows Server images available
ishare2 search linux      # Will show all Linux images available
ishare2 search forti      # Will show all Fortinet images available
ishare2 search palo       # Will show all Palo Alto images available
ishare2 search Licensed   # Will show all images with keyword "Licensed" in their name
```


_Search by type:_
```bash
ishare2 search bin          # This command will show all available images of bin/iol type
ishare2 search qemu         # This command will show all available images of qemu type
ishare2 search dynamips     # This command will show all available images of dynamips type
```



### Pull images:

_Syntax:_
```
ishare2 pull <type> <id>
```


```bash
ishare2 pull qemu 152
```



### Show installed images:


```bash
ishare2 installed all       # Will show all installed images from all types
ishare2 installed bin       # Will show all bin/iol images installed
ishare2 installed qemu      # Will show all qemu images installed
ishare2 installed dynamips  # Will show all dynamips images installed
ishare2 installed docker    # Will show all docker images installed
```
